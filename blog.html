Blog

1.Wat ik heb gedaan voor dossier 1

Ik ga eerst github verbinden met vsc. Het is belangrijk dat dit eerst gebeurt zodat ik de website kan laten draaien via github elke keer als ik een verandering aanmaak.

Nu ik de verbinding tussen github en vsc heb kunnen leggen moet ik eerst de basics gaan leren van hoe ik tekst en plaatjes op de website tezien krijg. Ik heb vooral simpele manieren gebruikt door in body h1, h2 en p te gebruiken en met een img command heb ik het plaatje op kunnen roepen met erbij hoe wijd hij moet zijn.

Na dit te hebben gedaan is het belangrijk om de drie pagina’s te laten werken. Ik wil dus een project.html en een blog.html aanmaken en in alle drie de de pagina’s een soort identiek makkelijk te gebruiken navigeer knoppen interface aanmaken. Allereerst maak ik dan gewoon simpele links aan op elke html zodat de basics van navigatie gelijk er zijn.

dit werkt ga ik de CSS indelen. Ik begin met kijken het linken van alle pagina’s met het style.css bestand. Zo volgen alle pagina’s dezelfde indeling logica. Ik test met het invoegen van een achtergrond plaatje en probeer die statisch en niet herhalend te laten zien.

Nu het achtergrond plaatje werkt kreeg ik het probleem dat de tekst niet leesbaar was dus heb ik een witte blok achter de tekst laten aanmaken doormiddel van een class aan te maken in css.
